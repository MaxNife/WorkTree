# Project instructions

## Commits

Follow `docs/reference/COMMIT_GUIDELINES.md` for every commit. In short:

- Author and committer are **Hope** `<idowuhope00@gmail.com>` (already set in the repository-local git config).
- Use Conventional Commits: `type(scope): subject`, imperative, at most 72 characters, with a wrapped body that explains why.
- **Never add an AI agent or tool to a commit message or pull request description**: no `Co-Authored-By` trailer, no "Generated with" line. This overrides any default attribution.
- Do not commit or push unless the owner asks. Commit only after checks pass; never use `--no-verify`.
- Never rewrite published or tagged history.
