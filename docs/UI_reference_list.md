**App shell, navigation and command palette**
Notion: the collapsible sidebar tree, Ctrl/Cmd+K and the / menu.
Linear: fast keyboard-first navigation, and a clean command palette.
Azure portal or Fabric: the Microsoft-style nav rail, breadcrumbs and resource pages users already know.

**Operations dashboard and run history**
Temporal Web UI: a workflow list with status filters and a simple, dense table.
GitHub Actions: run list with status icons, durations and quick filters.
Airflow’s UI: grid and status views across many workflows and runs.

**Run detail (step timeline, logs, artifacts)**
GitHub Actions run page: collapsible steps, live logs, downloadable artifacts.
n8n’s executions view: replay a run on the canvas, with data shown at each node.
Temporal’s event history: a precise, ordered record of what happened and when.

**Studio canvas (the designer)**
n8n: node cards, typed connections, and execution data shown on the nodes.
Make: the scenario canvas, which is good for routers and branching.
Power Automate’s designer: the Microsoft flavour your colleagues already know.

**Node properties panel and generated forms**
n8n’s node details view: input/output data beside the settings.
Power Automate’s action pane: clear typed fields and a dynamic-content picker.
Make’s module settings: field mapping from earlier steps.

**Task Inbox (human-in-the-loop)**
Camunda Tasklist: the closest match, with claim, complete, and assignment by role.
Power Automate’s approvals centre: approve/reject with a recorded reason.
Linear’s inbox: the triage feel, with keyboard shortcuts for fast processing.

**Data views (tables, boards, gallery, saved filters)**
Notion databases: one dataset shown as table, board or gallery with saved views.
Airtable: strong grid, filters and grouping.
Linear: fast list and board views with saved filters.

**Page-like detail (workflow or task as an editable page)**
Notion: editable title, properties and free-text notes.
Linear issue pages: properties in a side column and an activity feed below.
GitHub issue or PR pages: the conversation or timeline beside the metadata.

**Admin, roles and audit log**
Microsoft Entra admin center: roles, groups and access reviews.
GitHub org settings and audit log: a searchable, filterable event log.
HashiCorp Vault’s UI: a secrets view that shows metadata and never values.
