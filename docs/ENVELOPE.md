# Job / result envelope (schema version 1)

The envelope is the only contract between the control plane and a worker. It is
language-neutral JSON: a worker in another language (for example a .NET robot host) only
has to read one `JobEnvelope` and answer with one `ResultEnvelope`.

- Models: `app/domain/envelope.py`
- JSON Schema: [`docs/schemas/envelope-v1.json`](schemas/envelope-v1.json), generated by
  `scripts/gen_schemas.py` (`--check` fails CI when it is stale)
- Contract suite every activity must pass: `tests/contract/test_activity_contract.py`

## Job (control plane → worker)

| Field | Type | Meaning |
|---|---|---|
| `schema_version` | int | `1` |
| `run_id` | string | the run this step belongs to |
| `step_id` | string | the step id in the workflow definition |
| `iteration` | int | `foreach` item index (0 when not a foreach step) |
| `attempt` | int | the engine's attempt counter; a result is applied only to the same attempt |
| `activity` | string | registered activity name, e.g. `excel` |
| `inputs` | object | step inputs with step/input/run references already resolved. Secret references stay as `{{ secret:name }}` text |
| `secret_refs` | string[] | names of the secrets the inputs reference |
| `workspace` | string | absolute path of the run workspace; files travel by reference inside it |
| `correlation_id` | string | joins logs across control plane, worker and activity |
| `timeout_seconds` | int | the worker kills the whole process tree after this |

## Result (worker → control plane)

| Field | Type | Meaning |
|---|---|---|
| `schema_version` | int | `1` |
| `run_id`, `step_id`, `iteration`, `correlation_id` | | copied from the job, on every path including failures |
| `outcome` | `done` \| `failed` | the named outcome that drives `on_done` / `on_failed` routing |
| `outputs` | object | small JSON (≤ 512 KB). Bulk data is written to the workspace and referenced by path |
| `message` | string | human-readable summary, secrets masked |
| `artifacts` | `{name, path, sha256, bytes}[]` | files produced in the workspace (`path` relative to it) |

## Rules

1. **Secrets** are resolved by the worker, per call, from the secret store, and passed to the
   activity process on stdin together with the job. They are never written to the job row,
   the workspace, the result, or a log; every resolved value is registered with the masker.
   Platform secrets (`session_signing_key`) are never resolved for activities.
2. **Activities never raise.** Invalid inputs, exceptions, timeouts, crashes and unknown
   activities all become `outcome: failed` with a safe message.
3. **One child process per job.** On timeout the whole process tree (grandchildren included)
   is killed and the result is `failed` with `timed out after Ns`.
4. **Delivery is at-least-once.** A job can be redelivered after a crash; the engine ignores a
   result whose `attempt` does not match the step's current attempt, and ignores results for
   steps that are no longer dispatched. Activities should therefore be idempotent, or declare
   `resume: skip` on the step.

## Example

```json
{
  "schema_version": 1, "run_id": "9f2c…", "step_id": "report", "iteration": 0, "attempt": 1,
  "activity": "excel",
  "inputs": {"operation": "write", "path": "report.xlsx", "source_path": "matched.parquet"},
  "secret_refs": [], "workspace": "/srv/uaf/runtime/workspaces/9f2c…",
  "correlation_id": "c41a…", "timeout_seconds": 300
}
```

```json
{
  "schema_version": 1, "run_id": "9f2c…", "step_id": "report", "iteration": 0,
  "correlation_id": "c41a…", "outcome": "done", "outputs": {"rows": 1204},
  "message": "1204 rows written",
  "artifacts": [{"name": "report.xlsx", "path": "report.xlsx", "sha256": "ab12…", "bytes": 88214}]
}
```
